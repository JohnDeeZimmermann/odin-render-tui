# Odin Render TUI (ORT)
Odin terminal layout library for TUI applications. 

> [!warning]
> Work in progress. Basically nothing works as of now.

## Dependecies

The following libraries need to be installed:
* [odin-termbox2](https://github.com/JohnDeeZimmermann/odin-termbox2) (custom fork)
* [termbox2](https://github.com/termbox/termbox2)

## AI Usage
This project is purely recreational. AI is therefore used for research purposes only. AI is not used to generate parts of the code, except for documentation or very specific occasions.
